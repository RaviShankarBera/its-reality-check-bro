# Reality Check, Bro.

A small browser game that turns 36 political claims into four levels (balloon popping, dart the myth, final boss, rumour wildfire). Every claim ends with a plain-language reality check and links to the public reporting it is based on.

By Ravi Shankar Bera, Stacknity. Independent project, not affiliated with any party, the Election Commission of India or any movement. Reality checks summarise the linked pages as of October 2026; where reporting is mixed, the card says so.

Plain HTML, CSS and JavaScript. No build step. Open `index.html` or serve the folder with GitHub Pages.
